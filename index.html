Project 1 · Groundwork · Python · Apache-2.0

AI-conducted employee interviews where every finding resolves to a verbatim quote, or it doesn't ship.

In AI-transformation consulting, the slow step is interviewing dozens of employees. An LLM summarizing those interviews produces fluent, partly invented findings. I wanted findings that can be checked.

Two independent gates

  • Gate 1, Grounding: the quoted span must exist verbatim in the immutable transcript, or the claim is rejected.
  • Gate 2, Entailment: the quote must actually support the claim.

A fuzzer that attacks the gates

A property-based fuzzer tries to sneak claims past both gates and fails the build on any false accept.

It caught a real bug: "vendor I" matching inside "vendor ignores".

Privacy firewall

  • HMAC pseudonymization at ingest
  • Encryption at rest
  • k-anonymity and aggregate-only release

I found and fixed three real privacy leaks while building it.

Truth taxonomy

Findings are graded Tier 0 to 4, with calibration checks on stated confidence.

Honest status

The engine runs, with 273 passing tests 0 third-party dependencies, and the evaluation gate and fuzz audit run in CI on every push. It has never been run with real employees. The core thesis, that AI interviewers get more candid answers than human consultants, is untested; I have written an experiment design for it.

Run it: python3 -m ai_engine.cli --simulated --candor open. A guarded interviewee correctly produces zero findings.

Project 2 · "Tools, Not Leaks?" · Paper + code · MIT

When an AI agent with web search scores high on Humanity's Last Exam, is it reasoning or finding leaked answers?

A pilot audit on HLE-Diamond, 1,000 questions.

The protocol I specified: two independent blind solving passes, blind adjudication, answers locked with SHA-256 hashes before any grading, and grading isolated from the solvers.

I corrected my own claim. Version 1 read the web gap as leakage. Version 2 added controls, and they showed most of the gain is genuine tool use.

AI-use disclosure

AI agents did the solving, adjudication and judging. I designed the protocol and integrity rules, reviewed outputs, and wrote and edited the paper with AI assistance.

Pilot study, not peer reviewed.

RUU Robotika dan Sistem Kecerdasan Artifisial Terwujud

A draft Indonesian bill plus its Naskah Akademik (academic paper), Oct 13, 2026, following the format required by Indonesian law (UU 12/2011 as amended).
